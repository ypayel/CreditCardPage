# 🌐 Credit Card Page

---

## 🧭 Project Overview

This project is an interactive credit card details form that visually mimics a real credit card. Users can input cardholder name, card number, expiration date, and CVC. As the user types, the card front and back update in real time, providing immediate visual feedback. The form is responsive and works well on both mobile and desktop screens.

---

## 🧱 Technologies Used

- **HTML5 / CSS3 / JavaScript (ES6+)**

---

## 📱 Features

- Live Card Preview - card details are updated in real-time as the user types.

- Responsive Design - optimized for desktop and mobile viewports.

- Validation Ready - input fields are restricted in length to match typical card formats.

- Visual Styling - front and back card images, styled fonts, and interactive layout.

- Interactive Buttons - confirm button with hover effects.

- Modern UI - uses Space Grotesk font and soft color gradients for a clean design.
